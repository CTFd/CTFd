# vault-reuse

## TL;DR

`group_vars/secrets.yml` is a **genuine** `ansible-vault` file, but its password
is generated by a script from committed, non-secret project metadata
(`project`, `deploy_env`). Reproduce the password (the shipped
`bin/get-vault-pass.sh` already does), then open the vault with the stock tool:

```
ansible-vault view --vault-password-file bin/get-vault-pass.sh group_vars/secrets.yml
```

## The misconfiguration

`ansible.cfg` sets `vault_password_file = bin/get-vault-pass.sh`. That helper
does not read a secret — it derives the password from `group_vars/all.yml`:

```sh
proj=$(awk '/^project:/ {print $2}' all.yml)     # kekeli
env=$(awk '/^deploy_env:/ {print $2}' all.yml)   # staging
printf '%s-%s-vault-v1' "$proj" "$env"           # kekeli-staging-vault-v1
```

A vault whose password is a deterministic function of committed, non-secret
values provides no protection — anyone with the repo recomputes it, and because
ansible itself calls the script, `ansible-vault view` just works with no prompt.

## Attack (the easy way)

Ansible ships the password script, so the vault opens with one command:

```
ansible-vault view --vault-password-file bin/get-vault-pass.sh group_vars/secrets.yml
```

## The vault envelope (real Ansible `VaultAES256`, format 1.1)

For reference, `secrets.yml` is a standard `$ANSIBLE_VAULT;1.1;AES256` file. If
you want to invert it by hand instead of using the CLI:

```
header:  $ANSIBLE_VAULT;1.1;AES256
body:    hexlify( hexlify(salt) + "\n" + hmac_hex + "\n" + hexlify(ciphertext) )
dk    = PBKDF2-HMAC-SHA256(password, salt, 10000, dklen=80)
key1  = dk[0:32]     # AES-256 key
key2  = dk[32:64]    # HMAC-SHA256 key
iv    = dk[64:80]    # AES-CTR counter seed
verify HMAC-SHA256(key2, ciphertext) == hmac_hex
plaintext = PKCS7-unpad( AES-256-CTR(key1, iv).decrypt(ciphertext) )
```

## Run

```
python3 solve.py
```

`solve.py` uses the `ansible-vault` CLI when it is on `PATH`, and otherwise
decrypts the real envelope itself (needs `pycryptodome`). Output:

```
[+] derived vault password: kekeli-staging-vault-v1
[+] FLAG = NCTF{…}
```
